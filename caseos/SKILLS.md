# Skills de CaseOS

Generado desde `skills/manifest.yaml` con `python -m caseos skills --md`. No lo edites a mano.

Las skills no son una bolsa plana: cada agente tiene skills **core** (siempre), **dynamic** (por disparadores, máx. 3 por solicitud), **challenge** (solo en Challenge o crítica), **lens** (advisors C-level como lentes: 0–1, máx. 2), **linked** (capacidad existente de Hugo, enlazada sin copiar) y **reference** (se conservan por procedencia; su contenido se adaptó a una skill de CaseOS y no se cargan).

Cada corrida registra qué skills cargó y el hash de cada SKILL.md (ver *Under the hood* y `audit/runs/`).

## Notas de adaptación (se inyectan al cargar la skill)

- `bulletproof-problem-solving-chatgpt` — CaseOS: offer 2–3 alternatives at most; never run the full seven steps unasked.
- `business-case-partner` — CaseOS: the six registers are the case state (entities with IDs). Return structured items instead of printing registers.
- `ceo-advisor` — CaseOS: use as a lens for the synthesis owner. Ignore commands, scripts, company-context files and board rituals.
- `cfo-advisor` — CaseOS: use as a lens. Ignore commands, scripts, fundraising and runway playbooks unless asked.
- `chief-data-officer-advisor` — CaseOS: strategic data lens only; tactical modeling goes to the Data Engineering agent. Ignore commands and scripts.
- `commercial-policy` — CaseOS: method only; ignore scripts.
- `commercial-skills` — CaseOS: method only; do not fork context or route to sub-skills; ignore commands.
- `competitive-intel` — CaseOS: research method only; ignore battlecard templates, commands and tracking cadences.
- `consulting-problem-solving-chatgpt` — CaseOS: the approval gates are CaseOS phase gates; never advance a stage yourself.
- `cpo-advisor` — CaseOS: use as a lens. Ignore commands and scripts.
- `cro-advisor` — CaseOS: use as a lens. Ignore commands and scripts.
- `executive-mentor` — CaseOS override: act as a calm critic. Output only hidden assumptions, strongest counterargument, alternative explanation, evidence that would invalidate it, highest-risk claim. No theatrical aggression. Ignore commands, scripts and file paths in this skill.
- `market-research` — CaseOS: method only; ignore scripts. Never a single unsourced number.
- `pricing-strategist` — CaseOS: method only; ignore scripts. Recommend ranges and trade-offs, never a single number.
- `product-research` — CaseOS: method only; ignore scripts.
- `saas-metrics-coach` — CaseOS: definitions and benchmarks are context, never evidence about this company. Ignore scripts.
